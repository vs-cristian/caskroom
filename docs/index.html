macOS 15 or laterApple SiliconOpen source on GitHub

Everything brew manages, in one window.

Caskroom is a front end to the brew you already have. It runs it, reads its JSON, and never touches Homebrew's files.

Updates

One list for formulae and apps, with release notes per package, Update All, and a history of what Caskroom updated.

Services

brew services as Login Items: a switch for start at login, Run and Stop for right now, and the log one click away.

A page for every package

Version, installs this month, size on disk, what it needs and what conflicts with it, release notes, and the Terminal command behind every button.

Discover

Top apps, top command-line tools, what's trending and what's new in Homebrew, laid out like the App Store.

Search by command

Find packages by name, or by the command they install: rg finds ripgrep.

Revert

Puts a formula back to the version it had before its last update.

Adopt, free

Finds apps already in your Applications folder that Homebrew has a cask for and hands them over without downloading them again.

Off until you turn it on

Security

Checks installed formulae against OSV.dev with brew vulns and updates the ones that have a fix.

Maintenance

Clean Up with a preview of what it frees, Doctor, Export Brewfile, and warnings for deprecated or disabled packages.

Nothing hidden

Every button is a brew command.

Caskroom doesn't reimplement Homebrew. It runs the brew on your Mac, with your taps and your settings, and decodes what it prints.

Every package page ends with the exact commands behind its actions, ready to copy. The activity log shows the same text for everything Caskroom ran.

$ brew install --cask ghostty

$ brew install --cask --adopt google-chrome
